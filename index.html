Panduan Deploy ke GitHub Pages

Langkah praktis menghubungkan database gratisan ke aplikasi static yang di-host di GitHub Pages.

1

Pilih Database yang Cocok

Untuk GitHub Pages (static site), pilih BaaS / serverless: Firebase, Supabase, MongoDB Atlas + Realm, atau Neon + API.

2

Daftar & Buat Project

Ikuti materi di bagian Materi untuk registrasi. Ambil API Key / URL / Anon Key.

3

Integrasikan di Frontend

Gunakan SDK JavaScript (Firebase JS, @supabase/supabase-js, dll). Jangan taruh secret key di frontend — gunakan only public/anon key + RLS/Rules.

4

Push ke GitHub & Aktifkan Pages

Push folder project ke repository, Settings → Pages → Source: Deploy from branch (main / docs).

5

Uji & Monitor

Buka URL GitHub Pages, uji CRUD, cek console browser, dan pantau usage di dashboard database.

Tips Keamanan: Selalu aktifkan Row Level Security (Supabase) atau Security Rules (Firebase). Jangan pernah commit service account key atau secret ke repository publik.
